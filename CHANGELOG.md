# Changelog

All notable changes to SoundAnchor are documented here.

## [0.1.0] - 2026-08-13

### Added

- Event-driven Core Audio monitoring for input, output, and device-list changes.
- Automatic restoration of a selected microphone when Bluetooth output is active.
- Menu bar controls for protection, Bluetooth-only mode, input selection, manual repair, and launch at login.
- Optional hidden menu bar mode with a recovery control in the settings window.
- Universal Apple Silicon and Intel build.
- DMG packaging with an Applications shortcut.
- Local-only operation with no networking or telemetry.
