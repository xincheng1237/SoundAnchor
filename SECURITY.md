# Security Policy

## Supported versions

Security fixes are currently provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose user data or compromise a Mac. Use GitHub's private vulnerability reporting feature for this repository. Include a concise description, affected version, reproduction steps, and potential impact.

SoundAnchor does not require network access and does not inspect or record microphone content. A report suggesting otherwise should be treated as security-sensitive.
