# SoundAnchor 0.1.1

This update adds complete native interface localization.

## What's new

- English interface on English and other non-Chinese macOS language settings
- Simplified Chinese interface on Simplified Chinese macOS
- Localized menu bar menu, settings window, status text, error messages, and About dialog
- English remains the fallback when the current system language is not available

## Included from 0.1.0

- Event-driven Core Audio monitoring with no idle polling
- Automatic restoration of the selected input while Bluetooth output is active
- Optional hidden menu bar mode
- Universal Apple Silicon and Intel build
- No networking, telemetry, recording, or microphone-content inspection

## Requirements and beta notice

- macOS 13 or later
- This build is ad-hoc signed and has not yet been notarized by Apple. On first launch, Control-click the app and choose **Open**, or allow it under **System Settings → Privacy & Security**.
